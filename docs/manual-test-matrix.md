# Rack42 连接功能手动测试矩阵

> 适用版本：Phase 4/5（RDP/Web/SSH/SFTP + 设备凭据 + 类型管理）
> 测试凭据来自本地 `.secrets`，不得写入本文档、截图或提交记录。

## 1. 安全基线

| # | 检查项 | 操作 | 预期 |
|---|---|---|---|
| S1 | 默认不传 SSH 密码 | 设置保持默认（OpenSSH，自动填充关闭），从设备列表启动 SSH | 命令行只有主机/端口/用户名；客户端提示输入密码 |
| S2 | 自动填充警告 | 开启自动填充后保存 | 设置页显示红色风险提示 |
| S3 | 自动填充可关闭 | 关闭后重新启动 SSH | 密码不再出现在命令行 |
| S4 | RDP 无明文密码 | 启动 RDP，用 Process Explorer 查看 `mstsc.exe` 命令行 | 只有临时 `.rdp` 路径，无密码 |
| S5 | 临时 RDP 清理 | RDP 会话关闭后等待 2 秒，再重启应用 | `rdp/` 下无残留 `.rdp`，`rdp_sessions` 为空 |
| S6 | 审计不含密码 | 成功/失败各连接一次，打开审计页 | 只有动作、设备、凭据标签、目标、结果；无密码/用户名 |
| S7 | Web 审计脱敏 | 打开带路径/查询参数的 Web 地址 | 审计目标只保留 scheme + host + port |

## 2. RDP

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| R1 | 默认端口 | 凭据端口留空，类型 RDP | 启动 mstsc，连接目标为 3389 |
| R2 | 自定义端口 | 凭据端口设为测试机可用端口 | 目标地址带端口 |
| R3 | 有密码 | 凭据保存密码 | 无凭据输入框，直接进入 RDP |
| R4 | 空密码 | 凭据不保存密码 | mstsc 弹出凭据框 |
| R5 | 错误密码 | 临时改错密码 | 认证失败，应用本身不崩溃 |
| R6 | 取消登录 | 关闭 mstsc | 临时文件被清理，审计记录成功启动 |
| R7 | 主 IP 回退 | 凭据地址留空，设备有主 IP | 使用设备主 IP |
| R8 | 域账号 | 填写 RDP 域 | `.rdp` 带 `domain:s:` |

## 3. Web

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| W1 | 无 scheme | 地址只填主机/IP | 默认以 https 打开 |
| W2 | http | 地址写 `http://...` | 按 http 打开 |
| W3 | 自定义端口 | 端口填 8443 | URL 使用 8443 |
| W4 | 非法协议 | 地址写 `file:///...` | 拒绝并提示只允许 http/https |
| W5 | 无地址且无主 IP | 设备无 IP、凭据无地址 | Toast 提示未配置地址 |

## 4. SSH

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| H1 | 默认 OpenSSH | 设置默认，启动 SSH | 新控制台运行 `ssh -p <port> -l <user> <host>`，提示密码 |
| H2 | Xshell 7 | 设置 Xshell 路径，启动 SSH | 打开 Xshell 会话，无密码命令行（自动填充关闭） |
| H3 | PuTTY | 设置 PuTTY 路径，启动 SSH | `-ssh -P -l` 参数正确，提示密码 |
| H4 | 路径缺失 | 清空/填错 Xshell 路径并启动 | 提示未找到客户端，不崩溃 |
| H5 | 文件名错误 | 选择其他 exe 保存 | 保存被拒绝，提示文件名应为 Xshell.exe |
| H6 | 特殊字符密码 | 自动填充开启，密码含 `@ : / ? # 空格` | URL 编码后能连接；无明文出现在日志 |
| H7 | 主机指纹 | 首次连接测试机 | 客户端提示确认主机密钥 |
| H8 | 多凭据 | 同一 SSH 类型添加两条凭据 | 点击图标弹出选择，选中后启动对应账号 |

## 5. SFTP

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| F1 | 默认 OpenSSH sftp | 设置默认，启动 SFTP | 新控制台 `sftp -P <port> <user>@<host>` |
| F2 | Xftp 7 | 设置 Xftp 路径，启动 SFTP | 打开 Xftp 传输窗口 |
| F3 | psftp | 设置 psftp 路径 | `-P -l` 参数正确 |
| F4 | 多凭据 | 同一类型两条凭据 | 弹出选择并连接对应账号 |

## 6. 设备凭据

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| C1 | 新设备 | 新建设备后立即打开凭据标签 | 提示先保存设备 |
| C2 | 新增凭据 | 编辑设备 → 凭据 → 添加 | 保存后列表出现，设备列表出现连接图标 |
| C3 | 跟随主 IP | 保持开关开启 | 凭据地址为空，列表显示主 IP |
| C4 | 自定义地址 | 关闭开关并填写地址 | 保存后使用自定义地址 |
| C5 | 默认凭据 | 同类型两条凭据，设置第二条默认 | 第一条自动取消默认 |
| C6 | 清空密码 | 编辑凭据勾选清除密码 | `hasPassword=false`，连接时客户端提示 |
| C7 | 删除凭据 | 删除设备内凭据 | 列表刷新，设备连接按钮减少 |

## 7. 凭据类型

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| T1 | 新增类型 | 名称、动作、端口、图标后保存 | 设置表格出现，凭据表单可选 |
| T2 | 内置类型删除 | 点击内置类型删除 | 按钮禁用/后端拒绝 |
| T3 | 删除自定义类型 | 删除有关联凭据的自定义类型 | 凭据自动归入「其他」，不丢失 |
| T4 | 自定义图标 | 上传 PNG/JPEG/WebP | 表格与类型选择显示图片 |
| T5 | 拒绝 SVG | 上传 SVG | 提示只支持 PNG/JPEG/WebP |
| T6 | 图标过大 | 上传超过 100KB | 前端拒绝；后端二次校验 |
| T7 | 动作为空 | 新建类型不勾动作 | 保存成功，但设备列表不出现连接按钮 |

## 8. 审计与稳定性

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| A1 | 成功记录 | 成功启动任一连接 | 审计新增 success |
| A2 | 失败记录 | 客户端路径错误或启动失败 | 审计新增 failed + 简要错误 |
| A3 | 清空 | 审计页清空 | 列表为空，数据库记录清除 |
| A4 | 重启持久化 | 连接后重启应用 | 审计记录仍在 |
| A5 | 锁定状态 | 锁定应用 | 无法通过 UI 发起连接 |
| A6 | 数据库迁移 | 用旧库启动新版本 | 自动迁移到最新版本（0006 删除 `devices.mac`，0007 新增机柜拓扑布局表），历史数据保留 |

## 9. 拓扑交互

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| P1 | 拖拽建连 | 从 A 底部连接点拖到 B 顶部连接点 | 弹出「添加连接」，源设备=A、目标设备=B；取消后不产生连线 |
| P2 | 反向拖拽 | 从 B 顶部连接点拖到 A 底部连接点 | 弹窗仍按 `out → in` 归一化显示源/目标 |
| P3 | 右键菜单 | 右键设备节点 | 菜单显示连接动作、添加连接、管理凭据、编辑、删除 |
| P4 | 无凭据设备 | 右键没有凭据的设备 | 连接区提示「该设备还没有可连接的凭据」 |
| P5 | VM 嵌套 | 物理服务器下挂 2 台 VM | VM 显示在宿主机卡片内；拖动宿主机时 VM 跟随 |
| P6 | 嵌套限制 | 把 VM 设为另一台 VM 的宿主机 | 保存被拒绝，提示宿主机必须是物理服务器 |
| P7 | 宿主类型变更 | 把宿主机设备类型改为交换机 | 其 VM 自动解除归属并回到顶层 |
| P8 | 布局持久化 | 拖动宿主机后保存布局并重启应用 | 宿主机位置恢复，VM 仍在宿主机内 |
| P9 | 删除键 | 选中节点后按 Backspace | 节点不会被从画布移除 |
| P10 | 保留未保存拖动 | 拖动节点后修改设备名称 | 未保存的节点位置保持，不跳回旧布局 |
| P11 | 机柜容器 | 打开拓扑 | 每个机柜显示为卡片，机柜内设备（含宿主机）按 U 位从高到低排列在卡片内 |
| P12 | 空机柜 | 新建一个没有设备的机柜 | 拓扑显示该机柜卡片，提示「空机柜」 |
| P13 | 未分配机柜 | 存在未分配机柜的设备 | 这些设备单独排列在机柜列右侧 |
| P14 | 机柜布局持久化 | 拖动机柜卡片后保存布局并重启 | 机柜位置恢复，机柜内设备仍在卡片内 |
| P15 | 设备换机柜 | 编辑设备，改到另一个机柜 | 拓扑中设备移动到新机柜卡片内，高度重新计算 |
| P16 | 连线右键删除 | 右键连线的标签 | 弹出菜单显示两端设备与连接类型，点击「删除连接」后连线消失、右侧列表同步减少 |
| P17 | 点击连线高亮 | 单击任意连线 | 连线变粗、变绿并闪烁，两端设备卡片出现绿色高亮环 |
| P18 | 点击空白取消高亮 | 高亮后点击画布空白处或其它设备 | 连线与设备高亮恢复普通样式 |
| P19 | 机柜右键添加设备 | 右键机柜卡片，点击「在此机柜添加设备」 | 打开新增设备弹窗，所属机柜已预选该机柜 |
| P20 | 物理机右键添加 VM | 右键物理服务器，点击「添加虚拟机」 | 打开新增设备弹窗，类型为虚拟机、宿主机已预选 |
| P21 | VM 表单隐藏字段 | 新增虚拟机 | 表单不显示所属机柜、起始 U 位、占用 U 数、厂商、型号、序列号 |

## 13. IP 总览

| # | 场景 | 操作 | 预期 |
|---|---|---|---|

## 14. 端口延迟探测

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| N1 | 自动探测 | 打开设备列表，设备包含凭据 | 延迟列先显示「探测中…」，随后显示毫秒数 |
| N2 | 无凭据设备 | 设备没有凭据 | 延迟列显示「—」，不发起探测 |
| N3 | 不可达端口 | 凭据指向关闭的端口 | 显示「不可达」，悬停显示连接失败原因 |
| N4 | 多凭据 | 同一设备有多个凭据端口 | 显示最小延迟；悬停列出每个凭据的地址:端口与结果 |
| N5 | 端口解析 | 凭据端口留空 | 使用凭据类型默认端口（RDP 3389 / SSH 22 / Web 443） |
| N6 | 超时 | 目标 IP 不响应 | 最长 1.5 秒返回「连接超时」，页面不长时间卡住 |
| N7 | 手动刷新 | 修改凭据地址或端口后点击「刷新延迟」 | 按新配置重新探测并更新结果 |
